# Secretly: 30-second ad script

Calm, warm, slightly hushed voice (like telling someone a secret). Soft piano or lo-fi underneath.
About 2.5 to 3 seconds per frame. Captions on the frames already match the lines below.

| Frame | On screen | Voice-over |
|---|---|---|
| 01-home | "The thing you'd never say out loud…" | Everyone has a thought they've never said out loud. |
| 02-swipe | "Swipe if you've felt it too." | On Secretly, you swipe through the ones other people finally shared… |
| 03-result | "Turns out, you're not the only one." | …and find out you were never the only one. |
| 04-feed | "Real thoughts. No names. No profiles." | No names. No profiles. Just honest people. |
| 05-ask | "Ask what you're too embarrassed to ask." | Got a question you could never ask anyone you know? |
| 06-answers | "Get honest answers from people who've been there." | Ask it here, and get real answers from people who've been there. |
| 07-write-secret | "Give a secret…" | And every day, you can give a secret… |
| 08-sealed | "…get a stranger's secret back." | …and get a stranger's secret back. |
| 09-opened | "Send them one kind message." | Send them one kind message. That's it. |
| 10-come-back-tomorrow | "Three a day. Come back tomorrow." | Three a day. Then you'll want to come back tomorrow. |
| 11-end-card | "saysecretly.com" | Secretly. Say the thing you'd never say out loud. |

Tips
- Hook in the first second: start on frame 01 with the voice already speaking, no logo intro.
- Add a slow zoom (Ken Burns) on each frame in CapCut so stills feel like video.
- On 02 and 08, a soft "swish" / paper sound effect sells the swipe and the envelope.
